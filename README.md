# agents-with-proxy

Обёртки для запуска CLI-агентов через прокси. Прокси-переменные ставятся только
для запускаемого процесса, глобальное окружение не трогается.

| Скрипт | Агент | Прокси |
|---|---|---|
| `claude-with-http-proxy.sh` | Claude Code | `http://10.70.0.43:8888` (HTTP/HTTPS) |
| `codex-with-socks.sh` | Codex | `socks5h://10.70.0.43:1080` (SOCKS5) |

Аргументы прокидываются в агента без изменений:

```sh
./claude-with-http-proxy.sh                 # обычный запуск
./claude-with-http-proxy.sh --resume <id>   # возобновить сессию (из папки проекта)
./codex-with-socks.sh
```

Каждый скрипт снимает переменные «чужого» типа прокси, чтобы они не смешивались:
HTTP-версия делает `unset ALL_PROXY`, SOCKS-версия — `unset HTTP_PROXY/HTTPS_PROXY`.
`NO_PROXY` в HTTP-версии — только `localhost,127.0.0.1,::1`, то есть остальная
локальная сеть (включая сам `10.70.0.43`) идёт через прокси.

Адрес прокси зашит в скриптах — при смене сети правится там.
